# Apotex Case Competition: 제네릭 의약품 입찰 · 공급망 최적화

> 미국 제네릭 의약품 시장의 입찰(bid) 과정을 데이터로 지원하는 3단계 모델: **입찰 수주 확률 예측 → 수요 예측 → 공급 비용 최적화**

`R` `XGBoost` `Logistic Regression` `ARIMA` · Apotex 케이스 컴피티션 · 4인 팀 · 2020

---

## 1. 문제

- 미국 제네릭 의약품 시장은 경쟁사가 50곳이 넘고, 매출의 큰 부분이 고객 **입찰**로 결정됩니다.
- 입찰 하나를 평가하려면 여러 부서의 검토가 필요하고, 수주 후 물량을 대지 못하면 **공급 실패(Failure to Supply) 위약금**이 생깁니다.
- 그래서 세 가지 질문을 데이터로 풀었습니다.
  1. 이 입찰을 **딸 확률**은 얼마인가?
  2. 이 제품군의 **앞으로 수요**는 어떻게 되는가?
  3. 수주한다면 **얼마를, 얼마나 자주** 공급해야 비용이 가장 적은가?

## 2. 모델 1: 입찰 수주 확률 예측

**설명 가능한 모델과 정확한 모델을 함께** 썼습니다. 현업이 이유를 이해할 수 있어야 입찰 의사결정에 쓸 수 있기 때문입니다.

| 구분 | 모델 | 역할 |
|---|---|---|
| White box | Logistic Regression | 어떤 변수가 수주에 영향을 주는지 해석 |
| Black box | XGBoost | 복잡한 변수 간 상호작용을 학습해 예측 정확도 확보 |

- **후보 변수:** 시장 점유율, 경쟁사 수, 단위당 공급 실패율, 연간·월간 물량, WAC 가격, 수요 예측값
- **변수 선택:** 로지스틱 회귀에서 후진 선택법(backward selection)으로 변수를 골랐습니다 (AIC 2071.1).
- **XGBoost:** 수주/실패 이진 분류, 학습 75% · 테스트 25% 분할. Linear boosting과 Tree boosting을 비교하고, 감마(최소 손실 감소), 부스팅 횟수, 트리 깊이를 조정했습니다. 변수 중요도도 함께 확인했습니다.
- **결과:** 테스트 데이터 기준 예측 정확도 **약 73%**

## 3. 모델 2: 수요 예측 (시계열)

- 기록이 가장 많은 제품군(Product Family 332)을 골라 월별 수요 시계열을 만들었습니다.
- 계절성과 추세를 분해해 확인한 뒤 **ARIMA(0,1,0)**을 적합했습니다.
- 잔차의 자기상관을 **Box-Ljung 검정**으로 점검했습니다.
- **결론:** 해당 제품군의 수요는 앞으로 감소할 것으로 예측됐습니다.

## 4. 모델 3: 공급 비용 최적화

- 재고·생산·운송 비용을 합한 총비용을 최소화하는 **보충 수량(Q)과 보충 주기(k)**를 계산했습니다.
- 2018년 입찰 데이터에 적용했습니다.
